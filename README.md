# Kahoot Cheat Interface

Menú de asistencia avanzado para la plataforma Kahoot que permite visualizar respuestas correctas y automatizar la participación sincronizada mediante el análisis de la API de la plataforma.

### ✦ Características

*   **Extracción de Datos**: Consulta automáticamente la base de datos de preguntas de Kahoot utilizando el ID del juego.
*   **Feedback Visual**: Resalta en tiempo real las opciones correctas e incorrectas directamente en la interfaz del usuario.
*   **Auto-Respuesta Inteligente**: Función de respuesta automática con compensación de latencia (Input Lag) para optimizar la puntuación.
*   **Interfaz Flotante**: UI minimalista integrada en el navegador, minimizable y con controles de visibilidad (Hotkeys).

### ✦ Instalación

1.  Abra la consola de desarrolladores en su navegador (Ctrl+Shift+I).
2.  Copie el contenido íntegro del archivo `kahoot.js`.
3.  Péguelo en la consola mientras se encuentra en la pantalla del juego de Kahoot y presione Enter.

### ✦ Atajos de Teclado

*   `Alt + H`: Ocultar / Mostrar la interfaz del menú.
*   `Alt + X`: Eliminar completamente el script de la sesión actual.
